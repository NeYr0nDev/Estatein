# Руководство программиста системы «Estatein»

## 1. Технологический стек и архитектура
Информационная система спроектирована как Single Page Application (SPA) на базе фреймворка React с использованием архитектурного шаблона Next.js (App Router).

* **Основа:** Next.js (React), TypeScript.
* **Стилизация:** Tailwind CSS.
* **Анимации:** Framer Motion.
* **Картография:** `@pbe/react-yandex-maps` (JS API Яндекс.Карт).

## 2. Структура каталогов
* `/app` — директория маршрутизации (App Router). Содержит страницы (`page.tsx`) и конфигурацию контекста.
* `/components` — библиотека UI-компонентов (`Header.tsx`, формы, карточки).
* `/data` — статические структуры данных и массивы объектов недвижимости.
* `/public` — медиа-ресурсы, иконки (`/svg`) и изображения (`/img`).

## 3. Локальное развертывание проекта

### 3.1. Клонирование репозитория
```bash
git clone [https://github.com/your-username/estatein.git](https://github.com/your-username/estatein.git)
cd estatein
```

### 3.2. Установка зависимостей
В связи с использованием React 19 и библиотек картографии, установку пакетов необходимо выполнять со специальным флагом:

```bash
npm install --legacy-peer-deps
```
### 3.3. Запуск сервера разработки (HMR)
```bash
npm run dev
```
Интерфейс будет доступен по адресу: http://localhost:3000.

### 3.4. Сборка production-версии
```bash
npm run build
```

### 4. Развертывание (Деплой) на Vercel
Проект подготовлен к непрерывной интеграции (CI/CD) на платформе Vercel.
Сборка и деплой происходят автоматически при push в ветку main.
В корневом каталоге создан файл .npmrc с инструкцией legacy-peer-deps=true для предотвращения падения сборки на сервере из-за конфликтов peer-зависимостей.
