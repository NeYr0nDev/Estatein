# 🏢 Estatein — Платформа недвижимости

Учебный курсовой проект веб-приложения агентства недвижимости, разработанный с использованием современных фронтенд-технологий. Проект включает в себя каталог объектов, многоаспектную фильтрацию, интерактивную карту и калькулятор ипотеки.

🌐 **Live Demo:** [Посмотреть проект на Vercel](https://estatein-phi.vercel.app)

## 🛠 Технологии
* **Фреймворк:** Next.js (React)
* **Язык:** TypeScript
* **Стилизация:** Tailwind CSS
* **Анимации:** Framer Motion
* **Карты:** API Яндекс.Карт (`@pbe/react-yandex-maps`)
